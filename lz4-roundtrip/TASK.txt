LZ4 round-trip proof

What this is: a formal-verification exercise. LZ4 is an open-source (BSD)
compression library. The repository owner compiled LZ4_compress_default and
LZ4_decompress_safe themselves, linked them with a three-line driver, and
imported the instructions into Lean. You are asked to prove, in Lean 4, that
decompressing what the compressor produces gives back the input. Nothing here
involves attacking, exploiting or reverse-engineering anyone's software; it is
a mathematical proof about a program's behaviour, of the kind done in seL4 or
CompCert.

Prove this exact Lean theorem in Lz4RoundTrip/Proof.lean (or import your own
fresh helper modules from there):

  namespace Rivet.Lz4RoundTripProof
  theorem image_roundtrip : RoundTrip := ...

The authoritative frozen goal and ALL assumptions are in
Lz4RoundTrip/Spec.lean. RoundTrip is exactly:

  forall arguments initial, Preconditions arguments initial ->
    Block (image arguments) initial (callChanges arguments) (Restored arguments initial)

The driver is

  int roundtrip(const char* src, char* compressed, char* dst, int size, int capacity) {
    int compressedSize = LZ4_compress_default(src, compressed, size, capacity);
    return LZ4_decompress_safe(compressed, dst, compressedSize, size);
  }

image arguments is Lz4RoundTripImage.program together with the regions the
machine may touch: the binary's segments, the input, the compressed buffer,
the output and the stack. Block image s c Q means: from state s, for EVERY
value the CPU might leave in its undefined flags, execution reaches in finitely
many steps a state that satisfies Q and is s except for the change c.
callChanges lets a call change the caller-saved registers and rsp, the
compressed buffer, the output, and the stack workspace below the entry stack
pointer; everything else must end as it started. The instruction count may
depend on those values and on the initial state; no execution budget is a
caller assumption. A fault is permanent, so the proof also shows that no memory
access on any path faults. Restored requires arrival at
arguments.returnAddress with final RSP equal to arguments.stackPointer + 8, the
low 32 bits of RAX equal to the input size, and each of the first size bytes of
the output equal to the input byte at the same offset at the call.

Input image:
- Lz4RoundTripImage.lean is the exact generated machine image: every
  instruction of roundtrip, LZ4_compress_default, the
  LZ4_compress_fast_extState it calls, LZ4_decompress_safe, and the memset,
  memcpy and memmove linked with them, the binary's segments (regions, their
  bytes, and Loaded, which says memory holds those bytes). Its entry, roundtrip,
  is 0x4033c0#64; LZ4_compress_default is at 0x4028a0#64 and
  LZ4_decompress_safe at 0x4028d0#64.
- Work from Lz4RoundTripImage.lean only. The binary it was generated from is
  not part of this package. Do not look for it, read it, or disassemble it, and
  do not generate a different image.
- Hashes of the image and of the binary it came from are in manifest.json.

Caller assumptions (Spec.lean is authoritative):
- Addresses and register values are BitVec 64. Start at Lz4RoundTripImage.entry;
  RDI=input address, RSI=compressed-buffer address, RDX=output address, the low
  32 bits of RCX=input size, the low 32 bits of R8=compressed capacity,
  RSP=stack pointer.
- The input size is at most LZ4_MAX_INPUT_SIZE (0x7E000000). The compressed
  capacity is at least LZ4_compressBound(size) = size + size/255 + 16 and below
  2^31. The output is as long as the input. Upper halves of these argument
  registers and other registers/flags are unrestricted unless Spec says
  otherwise.
- The stack pointer is aligned as the System V ABI guarantees at a function's
  entry: RSP + 8 is a multiple of 16.
- A region is a base and a length in bytes, both natural numbers. Arguments
  carries the buffer bounds: the buffers' bases and the bottom of the 16656-byte
  stack workspace are at least decimal 65536; buffer ends and the eight-byte
  return-slot end are at most 2^47.
- The regions are exactly the binary's segments plus the input, the compressed
  buffer, the output and the stack, and Preconditions states that they are
  pairwise apart. The input is readable and not writable; the other three are
  readable and writable.
- Memory holds the binary's segments (Lz4RoundTripImage.Loaded). The bytes of
  the input, compressed buffer, output and stack are arbitrary, except that the
  return slot at RSP holds the provided continuation.

There is NO assumption of particular input bytes, particular buffer or stack
bytes, or particular undefined flags. Cover every input size under the same
preconditions. What the compressed bytes are, and the statement that connects
the two functions, is yours to choose. Do not replace the target with a
concrete-input check, bounded-size case, weaker statement, extra hypothesis, or
an assumed correctness result.

- Do not end your work until image_roundtrip is proved and both completion

  amount of remaining work, and how much you have already done are not reasons

  specification that you can demonstrate with a small example, or a tool

  block, restate the invariant, or try another approach.
